# Identidad visual

El banner usa ámbar por la miel y repite la silueta del spark de Galaxy AI. El nombre se renderizó con One UI Sans desde el dispositivo de desarrollo; el SVG contiene trazados, no distribuye el archivo de fuente. El spark conserva la geometría del icono del teclado Samsung y aparece azul junto al nombre. Estos elementos identifican visualmente la integración; no expresan afiliación ni respaldo de Samsung.

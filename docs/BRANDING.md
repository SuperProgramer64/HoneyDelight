# Identidad visual

El banner usa ámbar por la miel y repite la silueta del spark de Galaxy AI. El nombre se renderizó con One UI Sans desde el dispositivo de desarrollo; el SVG contiene trazados, no distribuye el archivo de fuente. El spark conserva la geometría del icono del teclado Samsung y aparece azul junto al nombre. Estos elementos identifican visualmente la integración; no expresan afiliación ni respaldo de Samsung.

El banner de esta preparación usa el lema «Se ve como Samsung. Predice con Delight.» y muestra la referencia de pruebas de la alpha, sin expresar precisión global. La app de actualizaciones conserva su interfaz ámbar nativa y sus iconos adaptativos; no necesita cargar el PNG del README.

La portada inglesa usa `assets/banner-en.svg` y `assets/banner-en.png`, con el lema «Looks like Samsung. Predicts with Delight.». El README español conserva `assets/banner.svg` y `assets/banner.png` con su lema original. Ambas versiones mantienen la misma composición y los mismos elementos gráficos.

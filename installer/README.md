# Referencias del instalador manual de desarrollo

Estos scripts se conservan para diagnóstico y recuperación de la instalación manual anterior. No son la vía principal de distribución y necesitan artefactos compilados compatibles junto a ellos. El instalador preparado no importa historiales ni contactos de Gboard.

Para el ZIP directo usa `module/` y `docs/INSTALLATION.md`. Para reconstruirlo desde código usa `scripts/build-device-payload.sh`.
